Mol-Projector

分子结构转换工具

Date2026-06-04
Open link →

一个 Python 工具，把三维分子结构（如 XYZ、ARC、SDF 等格式）自动转换成二维 MOL 格式。核心功能是根据原子坐标自动推断化学键类型（单键、双键、三键），无需手动指定。

支持命令行批量处理和 Python API 两种用法，另有分子碎片分解子命令。MIT 协议开源。
